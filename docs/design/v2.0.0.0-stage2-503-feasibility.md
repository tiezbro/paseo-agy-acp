## 4. 单一合同裁决

本 Stage 的唯一 disposition 是 `SOURCE_FIELD_GAP + REAL_PROVIDER_REQUIRED + SOURCE_IDENTITY_UNKNOWN`：不建立 trusted-503 physical contract，依赖门保持关闭。

- 不授权 phrase -> HTTP 503/UNAVAILABLE/MODEL_CAPACITY_EXHAUSTED 归一化，不授权版本 gate、cooldown 触发或正式 parser fixture。
- unknown/transport fallback 必须 fail closed，不创建 capacity cooldown，不能用未证实的分类堵住队列。
